# 摆臂重绘记录

用户指出 v4 的手臂摆动幅度太小、不像正常走路。本轮重画前后摆臂极值、经过身侧和向前摆的中间姿势；E、H 两张完整人物图作为后摆中间姿势保留。双臂与双腿反向配合。

使用内置 imagegen 编辑完整人物，配合单独的姿势示意图。最终动画没有拆分手臂、关节旋转、道具覆盖或淡化补帧。脚部姿势与主体比例以 v4 为参考保持。程序只移动和缩放整张图进行配准。

第一批 B、D 在身侧姿势生成时保留了旧手臂，出现三条手臂，已拒绝。B2、D2 单独纠正后，复核确认各两条手臂，才纳入样片。F、G 第一批中间姿势过于接近前摆极值，F2、G2 将手掌收回至工牌下方的中间位置。四张拒绝版本均保留追溯，不进入样片。

检查标准：

- 前摆手掌明显在腹部前方，后摆在躯干后方，经过身侧时回到中间。
- 两臂相反方向摆动，近侧脚向前时近侧臂向后。
- 肩部和上臂参与运动，肘部微弯，宽袖随姿势改变。
- 每帧只有两条手臂、两只手；连接自然，不保留旧肢体。
- 正常速度与半速循环检查，最后一帧接回第一帧没有反相。

逐帧复核：近侧手掌从后摆的身体右后方，经身侧，到前摆的身体左前方，再返回。每帧各两臂；A/C 与近侧腿反相。新版已在浏览器循环检查，并保留 v4/v5 对照。状态仍是待复核样片，未安装到桌宠。工牌的遮挡与文字、衣褶、鞋形和发色一致性仍是后续修整项。动作数量和技术测试均不代替美术验收。

重建：在本包运行 `python sources/keyframes-v5/register.py`，再运行 `python build.py --draft-only --revision v5`。上一版仍可用 `--revision v4` 重建。预览页支持切换两版对照。
