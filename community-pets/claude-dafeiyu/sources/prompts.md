# 多帧动作表生成记录

## 0.3.0 分层角色与步态素材

仍使用内置 imagegen、真实透明背景，没有 API key。新增源文件均保存在本目录：

- `puppet-atlas.png`：以原始 idle 为参考，生成正面头部与长发、左右袖手、左右腿、鲸尾、闭眼头部的 atlas；服装、蓝发鲸耳鲸尾与原画风一致，各部件透明隔离。实际边界经目视确认后写入 `puppet.py`，没有盲目按等格切。
- `torso.png`：以 atlas 为编辑目标，单独输出无袖躯干。要求移除两侧袖子、手臂和手，保留领口、蝴蝶结、挂绳、Claude 工牌、小花、口袋、裙和白蕾丝；禁止头、腿、尾巴及其他部件。
- `walk-sheet-v3.png`：以原始 idle 为参考的八帧朝左走路表，逐帧指定近腿/远腿的接触、承重、通过与摆动，并要求固定头部和脚底基线。结果仍有重复姿态，因此最终自然步态没有直接播放该表。
- `profile.png`：以上述朝左表为参考，输出朝左上半身，保留头发、耳朵、头饰、卫衣、裙、尾巴，移除双臂、双腿、鞋，透明背景。最终与独立袖手和双关节腿组合，工牌文字由渲染器补为 Claude。

最终动作映射见 `action-catalogue.json`。自然走路采用支撑期落地、摆动期抬脚的关节求解，屏幕位移交给宿主。

使用内置 imagegen，`transparent_background: true`；没有调用付费 API 脚本或使用 API key。每张图为独立调用。参考图来自接手前已有的 `D:\project\output\imagegen\claude-dafeiyu`。下面记录生成提示词的动作与不变量，供继续迭代。

共同要求：生产用桌宠 sprite sheet，横向 2:1，4 列 × 2 行，共八个等大单元；顺序先上排后下排。真实透明 alpha；不画网格、编号、背景、地面或阴影。单元内角色完整，保留呆毛、头发、尾巴、鞋；每帧相同体型、头部位置与脚底/手臂基线。原有日系赛璐璐风格，深浅蓝渐变长发、白边鲸鳍耳、鲸尾、橙色星芒发夹、奶油白卫衣、焦糖蝴蝶结、橙星袖口、花朵徽章、Claude 工牌；全身款还保留卡其裙、白色袜套与棕鞋。不能把八帧画成同一姿势的位移。

## lean-sheet.png

参考 `lean.png` 为姿势和人物，`idle.png` 仅确认服装。八帧依次：正常托腮；头轻靠向手掌；再靠一点且眼睑降低；完全闭眼眨眼；半睁眼且头开始回正；头回到中心、尾尖轻摆；头向另一侧轻歪、鲸耳略抬；回到接近第一帧。必须是连贯的轻微头部动作与眨眼，手掌始终正确贴着脸。不画脚或桌子。

## walk-sheet.png

参考 `walk.png` 为精确朝右侧面和设计，`idle.png` 确认角色。八帧原地走路：右腿前落脚、左腿后蹬；右膝承重左脚抬跟；左腿从右腿旁经过；左膝前摆右脚跟抬起；左腿前落脚右腿后蹬；左膝承重右脚抬跟；右腿经过左腿；右膝前摆，连接第一帧。手臂与腿反向摆，头稳定，头发和尾巴轻随动，脚腿轮廓必须实际变化。

## wave-sheet.png

参考 `click.png` 为精确设计，`idle.png` 为开始/结束中立姿态。特别强调人物在单元内只占 70% 高，四边充分透明留白。八帧正面挥手：双臂垂下；右臂（观众左侧）开始抬起；手掌靠近脸；张掌向外挥且闭眼；向内挥并睁眼；再向外挥一次、左手叉腰；右手放下；回到中立。保证手、袖口连接，无多指、多肢体；工牌文字要求精确 Claude。生成结果仍存在部分帧工牌细节波动，未声称文字逐帧一致。
