# 随机日常与动作链

0.7 用独立时钟安排自主活动。每三分钟抽取 1～3 个时间点，落在第 12～168 秒之间，两个计划时刻至少相隔 25 秒。这个时间表不等待当前待机视频结束；待机视频会循环，直到活动开始。

到时间后，80% 概率选择一条可用动作链，否则选择一个可用单动作。动作链按顺序播放，中间的小憩、演奏等可以停留几个循环；完成后回到待机，下一活动之间另留至少 18 秒的安静时间。活动过长、用户操作或工作导致错过的时刻直接跳过，不会堆积在之后补播。

## 托腮：5 条

| 活动 | 顺序 |
|---|---|
| 有点困，眯一会儿 | 哼歌 → 眯眼小憩约 18 秒 → 拨头发 |
| 拨拨头发，看看你 | 拨头发 → 摇尾 |
| 开心哼两句 | 摇尾 → 哼歌 → 摇尾 |
| 揉揉眼睛，休息一下 | 拿电脑 → 打字 → 揉眼伸肩 → 收电脑 → 小憩 |
| 想明白，记下来 | 拿电脑 → 思考 → 打字 → 收电脑 |

真实工作优先于自主活动。如果恰好已经在自主打字，真实工作会接管已打开的电脑，避免再拿一次。工作结束后收起电脑，之后才恢复自主时间表。固定位置会排除包含移动的链，文字类动作沿用镜像限制。

这些链是已有完整人物片段的有序组合，切换沿用现有播放器；不等同于为每对姿势额外绘制过渡帧。托腮小憩仅复用已存在的闭眼完整画面，没有拼接四肢或生成新画面。精确顺序和重复次数由 `build_ambient.py` 生成，留档为 `sources/activity-chains.json`。

验证包括调度假时钟、真实桌面播放薄壳、实际部署 bundle 的加速仿真、配置兼容与全动作引用检查。预览的“10 倍”只影响预览时钟和视频，不改变真实桌宠的三分钟时间表。
