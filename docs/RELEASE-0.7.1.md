# Claude 大肥鱼 0.7.1

Claude-大肥鱼-站立 / Claude-大肥鱼-托腮：两种形态，119 段透明动画，16 条随机日常动作链。

![两种形态](https://raw.githubusercontent.com/123pc/dsh-pet/claude-v0.7.1/docs/media/hero.png)

[在首页看动作动图](https://github.com/123pc/dsh-pet#readme) · [安装说明](https://github.com/123pc/dsh-pet/blob/claude-v0.7.1/docs/INSTALL.md)

## 下载哪个

- **直接玩桌宠：`claude-dafeiyu-windows-x64.zip`**。解压到可写文件夹，双击 `启动桌宠.cmd`，不需要 DSH 或 Node.js。右键 → 换装；托盘 → 退出。配置独立保存在文件夹内的 `data/`。
- **已有 DSH：`dsh-pet-0.3.8-claude.1.tgz` + `claude-dafeiyu-pet-pack.zip`**。先安装本分支引擎，再使用角色包安装器；任务状态联动使用此模式。
- `SHA256SUMS.txt`：发行文件校验值。
- `THIRD-PARTY-SOURCE.zip`：内含 GPL 组件的对应源码，许可与来源见仓库 THIRD-PARTY.md 及发行包 licenses/。本项目对应源码在本页的 Source code 中。

本轮完成完整构建检查、119 段视频透明通道与哈希验证、角色安装升级卸载回归，以及独立解压启动检查。macOS / Linux 尚无对应实机验收；本次提供 Windows x64 解压版。
