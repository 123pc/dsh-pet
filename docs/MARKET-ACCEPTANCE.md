# 0.7.2 市场安装验收

环境：Windows x64；DSH 官方 Desktop / web CLI 0.2.1-rc.3；桌宠 Electron 43.3.0。验收使用独立 `DSH_HOME`、DSH userData 和桌宠 Electron profile，未替换日常使用的插件与数据。

## 安装产物

从最终 `dsh-pet-claude.tgz` 分别安装到全新的 web / Desktop 数据目录；不运行角色安装脚本，不依赖原开发目录。实际安装的 `lib/index.js` SHA256 与 TGZ 内相同。包内清单的 121 个文件逐一校验，通过：119 个视频、2 份形态配置。

两个新目录均自动准备三种可选形态：原版隐藏、Claude 站立显示、Claude 托腮隐藏；自动话语与余额查询关闭。旧配置、用户修改视频、重复启动、损坏清单、越界路径和符号链接保护另由 8 项初始化测试覆盖。

## 实际播放

- web：真实 DSH 页面视频达到 `readyState=4` 并推进播放时间；右键 → 换装显示指定名称，点选「Claude-大肥鱼-托腮」后托腮画面正常播放。
- Desktop：切换为托腮后，工作状态依次播放拿出并打开电脑 → 揉眼伸肩 → 轻敲键盘 → 收起电脑 → 托腮陪伴；同一工作状态更新任务文本未重复拿出电脑。
- Desktop：只在测试配置中将随机窗口缩短到合法的 30 秒，并限定魔术链；真实视频依次播放扑克魔术 → 变鸽子 → 凭空生花 → 挥手 → 待机。结束后恢复发行配置的 180 秒随机窗口。

Desktop 验收通过插件公开接口触发状态，观察真实 Electron 视频的 `playing` / `ended` 事件；验收副本只增加 profile 隔离与只读观察器，其余运行时代码逐字节保留。Desktop 的实体鼠标右键命中未列为通过项；web 右键菜单已实际操作。
